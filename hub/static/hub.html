Add a server

The server connects out to this hub over HTTPS – no port has to be opened on the server or its router.
  1. Install Server Monitor on the server (run start.bat).
  2. Open its web page → Update tab → Cloud monitoring.
  3. Paste the hub address and hub key below, click Connect. The server appears here within seconds.
